# Large statement ingestion performance evidence v1

Controlled run: 2026-08-29. The synthetic one-million-row CSV generated by `scripts/generate-million-row-statement-fixture.js` was streamed through the generic delimited parser without loading the file into memory.

- Parsed data rows: 1,000,000
- Parser elapsed time: 1,394 ms in the local controlled runtime
- Heap in use at completion: 11 MB
- Result: parser capacity demonstrated; end-to-end database ingestion throughput is not yet certified
- Ten-million-row support: projected, not certified

This fixture is synthetic, non-authoritative, testing only, not evidence of money owed, not a legal conclusion, and not part of the live NAIM rights profile. Local parser throughput is not a claim about production network or database throughput.
